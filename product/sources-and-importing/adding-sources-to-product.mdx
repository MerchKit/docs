# Adding sources to a product

A product may have both a specification sheet and an installation guide. Keep those documents linked to the product, then edit their source details in Merchkit so your team can find the right information.

## Before you start

Open a product in **Catalog → Products**. You need permission to manage data sources (`data_sources.manage`) to edit source records. Saving shared editor columns separately requires permission to manage views (`views.manage`). Ask a workspace administrator if an edit or save control is unavailable.

Source attributes and their names depend on your workspace. These edits change the source record in Merchkit; they do not modify the supplier's original file. A source linked to several products is shared, so changes to its attributes affect that shared record.

## Open and edit a product's sources

1. Find the product's **Data Sources** cell and double-click it to open the source editor.
2. Use the column visibility control to show the source attributes you need. Search for an attribute if the list is long.
3. Edit an editable cell, such as the filename or an existing label attribute. For example, distinguish `Chair specification sheet` from `Chair installation guide`. Use the columns your workspace provides rather than adding text to the URL field.
4. Finish the cell edit and check the value in the table. There is no separate document-save action for these attribute edits.
5. To work in the full Sources page, click **Open in Sources**. It opens a new tab filtered to the sources linked to this product.

The source editor has no document preview pane. For a source with an HTTP URL, use the **Open in new tab** row icon. URL sources also offer **Refresh source**, which schedules a refresh of the source information. These actions are not available for every source type.

## Add a supplier URL

1. In the editor footer, paste the URL into **Enter a URL to scrape**.
2. Click **Add URL**.
3. Wait for processing to complete, then check that the source appears in the product's list.

Scheduling the URL is not the same as finishing the scrape. If processing fails, verify that the page is accessible and use [Import and source troubleshooting](/product/troubleshooting/import-source-errors).

## Add text or upload documents

1. Click **Add** in the footer.
2. Choose **Add text source**, paste the supplier text, then click **Add text source** to save it. Alternatively, choose **Upload files** and select your documents.
3. Check the source list. Text is added directly; uploaded files require processing before their content is ready to use.

Use readable supplier content. An attachment alone does not prove the AI has extracted the right information; [review generated values against their sources](/product/attributes-and-enrichment/reviewing-ai-content).

## Save useful columns for the team

Image and source editors each have their own account-wide default view.

1. Open the source editor and choose the columns you want visible with the column visibility control.
2. Adjust column widths if needed.
3. Click **Save view**. Its tooltip says **Save the current columns as the account default for this editor**.
4. Reopen a source editor to check the saved layout. Repeat in a product's image editor to set its separate default.

This requires `views.manage` and changes the default for your account, not just your own session. The saved editor configuration concerns columns, including their widths; it is not a saved product filter or sort. New attributes are not automatically added to an already saved set of visible columns. To include one, show it and save the view again.

## Remove a source from a product

1. Select the source row.
2. Open **Remove** in the footer.
3. Choose **Unlink from product** to keep the source in your library but remove this product's link.

**Delete permanently** is a different action and is available only when the source is unused elsewhere. Do not delete a source just to tidy one product's list.

## Troubleshooting

- **A column is missing:** check the editor's column visibility control and account-default view. Column labels are workspace-specific.
- **A value is read-only:** check your data-source permissions and whether the attribute itself is editable. The inverse **Products** reference is read-only.
- **Refresh is missing:** it applies to URL sources. Text and uploaded-file sources do not have the same refresh action.
- **The source is linked, but a generated value has no citation:** citations are optional and appear only on supported new prompt generations. See [AI review limits](/product/attributes-and-enrichment/reviewing-ai-content#when-a-source-is-missing).

For larger imports, see [Bulk importing sources](/product/sources-and-importing/bulk-importing-sources). For image selection, see [Managing product images](/product/sources-and-importing/managing-product-images).
